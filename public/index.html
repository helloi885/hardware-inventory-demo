嘉立创怎么导出 Gerber 和 BOM

Gerber（制板文件）

  1. 嘉立创 EDA：文件 → 导出 → PCB制板文件(Gerber)…
  2. 文件名只用英文或数字，例如 Gerber_PCB1_2026-09-09
  3. 选项选 一键导出，不要勾彩色丝印
  4. 点 导出Gerber，得到 ZIP，再点本页「打开 Gerber ZIP」

要在板上点亮焊盘，同一菜单再导出 坐标文件(CPL) 或 飞针测试文件，用「加载坐标」导入。一键导出的 ZIP 一般不含 BOM。

BOM（物料清单）

  1. 嘉立创 EDA：文件 → 导出 → 物料清单(BOM)…
  2. 文件类型选 XLSX
  3. 右侧列必须有下面四项；位号、封装的「分组」选 是
  4. 点 导出BOM，再点本页「加载 BOM」
